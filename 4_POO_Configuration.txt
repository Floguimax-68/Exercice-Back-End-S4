5.1. Utilisation d'une classe 
Lorsqu'on conçoit une application, il est recommand é de centraliser les paramètres de configuration da ns un 
fichier : c'est ce qui a été fait dans le fichier config/config.php.  
 
• Renommez le fichier config.php  en config.class.php . Définissez une classe Config  dans ce 
fichier et ajoutez-y les propriétés requises en les  initialisant avec les valeurs permettant de faire 
fonctionner le site. 
• Instanciez l'objet $Conf  à partir de cette classe dans le fichier index.php , avant le routeur, et faites 
le nécessaire pour que le site fonctionne à nouveau . 
• Indication : L'objet $Conf  est une variable globale  de l'application.  
 En PHP, une variable globale n'est pas visible dan s une classe. Pour rendre une variable globale 
accessible dans une méthode, il faut la déclarer en  tant que tel, au début de cette méthode, avec 
l'instruction : global  $Conf ; 
5.2. Déclaration de valeurs constantes dans une cla sse  
La déclaration d'une valeur constante dans une clas se se fait avec le préfixe const . 
 
Exemple :  
public  const  CONSTANTE = "abc" ; 
 
Par convention, le nom d'une constante s'écrit en c aractères majuscules. 
 
Par défaut, la portée d'une constante est public , mais on peut lui affecter protected  ou private , comme 
c'est le cas pour n'importe quelle propriété ou mét hode. 
 
Un accès direct à un élément constant (ou statique : voir chapitre suivant) d'une classe peut se faire  avec 
l'emploi de l'opérateur de " résolution de portée " noté :: .  
 
Cet opérateur impose de désigner la classe dans laq uelle l'élément est accédé. 
Syntaxe : classe ::élément  
 
Plusieurs cas peuvent se présenter : 
• maClasse ::CONSTANTE  : Accès direct à l'élément CONSTANTE  déclaré dans la classe maClasse .  
 Dans ce cas, il faut que l'élément soit public . 
• parent ::CONSTANTE  : Accès à l'élément CONSTANTE  définie dans la classe parente (dans le cas d'un 
héritage ou extension de classe). 
 L'élément doit être public  ou protected . 
• self ::CONSTANTE  : Accès à l'élément CONSTANTE  déclaré dans la classe où on se trouve. 
 L'élément peut être public , protected  ou private . 
 
A noter : Les valeurs constantes d'une classe ne so nt pas instanciées pour chaque objet (une constante  est 
commune à tous les objets issus de la classe). 
5.3. Les propriétés et méthodes statiques 
Une propriété ou une méthode statique appartient à la classe et non à l'objet instancié à partir de ce tte classe : 
• Une propriété statique aura la même valeur pour to us les objets issus de cette classe. 
• Une méthode statique aura le même comportement dan s tous les objets issus de cette classe. 
 
La déclaration d'une propriété ou d'une méthode sta tique se fait avec le préfixe static . 
Exemples :  
• Déclaration d'une propriété statique : public  static  $maProprieté ; 
• Déclaration d'une méthode statique : public  static  function  maMéthode () {    }

• maClasse :: $maPropriété  : Accès à une propriété statique déclarée dans la classe maClasse .

Remarques :  
• Une propriété statique déclarée dans une classe ne  pourra pas être modifiée à partir d'un objet 
instancié à partir de cette classe, mais uniquement  à partir des méthodes de cette classe. 
• Les propriétés et méthodes statiques d'une classe peuvent être utilisées directement, sans qu'un 
objet de cette classe ne soit instancié . 
• L'opérateur habituel self ->maPropriété  ou $this ->maPropriété  n'est pas autorisé pour un 
élément statique. Seul l'opérateur de " résolution de portée " ::  est autorisé. 
 
Différences en $this  et self  :  
• $this  désigne l'objet courant, instancié à partir d'une classe, ou la classe courante. Les propriétés et 
méthodes "dynamiques" sont accédées avec l'opérateu r ->. 
• self  permet d'accéder aux éléments statiques définis da ns une classe avec l'opérateur :: . 
5.4. Configuration par défaut – Configuration perso nnalisée 
Afin d'améliorer la conception du site Magasin, il est utile de prévoir une configuration "par défaut" , avec des 
paramètres censés faire fonctionner le site dans la  plupart des cas.  
Cette configuration par défaut devra être personnal isée avec les paramètres spécifiques à l'installati on du site 
pour que celui-ci fonctionne correctement. 
 
Principe : 
La mise en œuvre repose sur l'utilisation de deux f ichiers : 
• includes/default_config.php  : Initialise les paramètres de configuration par d éfaut

• config/config.class.php  : Contient la définition des paramètres de configu ration personnalisés

site : 
 Si un paramètre est défini dans config.class.php , il remplace la valeur par défaut initialisée dans  
default_config.php .
