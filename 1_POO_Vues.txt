Dans l'état actuel du site, les scripts chargés de générer les Vues présentent tous la même structure : ils 
initialisent les variables qui seront affichées dan s le gabarit.  
Cependant, seules les variables $titre  et $contenu  diffèrent entre les Vues… 
 
Afin d'optimiser la programmation, nous allons cent raliser la création des Vues dans la classe Vue  (récupérez 
le fichier vue.class.php ) : 
 
<?php  
/*************************************  
Classe chargée de l'affichage des vues  
*************************************/  
class  Vue  { 
... 
 
La classe vue  comporte : 
• Un constructeur chargé d'initialiser la propriété $fichierVue  à partir du nom de l'action demandée. 
Exemple : Si $action  = "Clients ", alors $fichierVue  contient "vue/vue Clients .php ". 
• La propriété $fichierVue  qui contient le nom du script permettant de génére r le contenu et le titre 
de la page (stockés dans les variables $contenu  et $titre ). 
• La méthode afficher ($data ), chargée de générer la vue appropriée à partir des  données 
transmises dans le tableau $data . 
 
Au niveau du Contrôleur, l'appel des vues se fera e n instanciant un objet de la classe vue . 
 
Exemple : Affichage de la liste des clients dans le  Contrôleur 
$vue  = new  Vue ("Clients" );                      // Instancie la vue appropriée  
$vue ->afficher (array ("clients"  => $clients ));   // Affiche la liste des clients 
dans la vue  
 
Remarque : Le paramètre de la méthode afficher () est un tableau associatif.  
 Les valeurs stockées dans ce tableau associatif vo nt être extraites dans des variables nommées selon leur 
clé à l'aide de la fonction extract ()  (cf. manuel PHP). 
 Dans l'exemple ci-dessus, le résultat de extract ()  produira la variable $clients , qui sera utilisée dans 
le script vue Clients.php . 
 Le script vue Clients.php  ne génère plus que les variables $contenu  et $titre .
